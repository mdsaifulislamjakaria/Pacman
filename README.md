# Pacman Game

This is a simple 2D Pacman game that I built using Java. It uses Java Swing and AWT for the graphics and user input. The player controls Pacman to eat all the food while avoiding four ghosts.

## Gameplay
The goal is simple: Eat all the food dots while avoiding the four colorful ghosts. If a ghost touches you, you lose a life.

* Use the Arrow Keys (Up, Down, Left, Right) to move Pacman.
* Eat all the white dots on the screen to score points.
* Avoid the ghosts. If a ghost touches you, you lose a life.
* You have 3 lives. If you lose all of them, the game is over.
* Press any key to restart the game after a Game Over.

## Main Features
* **Movement**: Pacman moves smoothly in four directions.
* **Ghosts**: There are 4 ghosts that move randomly around the map.
* **Collision Detection**: The game checks if Pacman hits a wall, eats food, or touches a ghost.
* **Score System**: You get 10 points for every food dot you eat.
* **Map Design**: The game level is created using a tile-map system.

## Tools Used
* **Java**: The main programming language.
* **Swing**: Used to create the game window and panels.
* **AWT**: Used for drawing images and handling keyboard input.

## Project Files (In src)
* `App.java`: This is the main file that starts the game and sets up the window.
* `PacMan.java`: This file contains the game logic, including how characters move and how the game is drawn.

## How to Run the Game
1. Download or clone this project: https://github.com/mdsaifulislamjakaria/Pacman
2. Open the project in an IDE like IntelliJ IDEA, VS Code, or Eclipse.
3. Run the `App.java` file.
